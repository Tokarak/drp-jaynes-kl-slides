In z, changing \lambda only shifts the curve, by -\log\lambda: a scale family becomes a location family.

Top: changing λ stretches the curve. Bottom: the same distributions in z = log x only slide, by −log λ. The density picks up the Jacobian dx/dz = e^z = x; the cdf doesn’t. Exponential is a scale family, and in log coordinates a scale family is a location family. That’s why “no idea about the scale” will mean flat in log λ.

Neyman–Pearson: the likelihood ratio is all you need

Take H_0 = B (good batch) and H_1 = A (bad batch).

  • Type I error \alpha: rejecting a good batch. Type II error \beta: accepting a bad one.

Neyman–Pearson lemma (1933). Among all tests with type I error \le\alpha, the one with the smallest \beta rejects H_0 when \frac{P(D\mid H_1)}{P(D\mid H_0)} > k \quad\Longleftrightarrow\quad \text{evidence for } H_1 > 10\log_{10}k \,\mathrm{dB}.

  • Thresholding Jaynes’ evidence is therefore the optimal frequentist test.
    • The two schools disagree on how to choose k: Jaynes uses prior odds and losses (Ch 13–14), Neyman–Pearson uses a fixed \alpha.

The law of large numbers, applied to log-likelihood

Data x_1,\dots,x_n come independently from p_{\theta^\ast}. For any \theta: \frac1n\log\frac{L(\theta)}{L(\theta^\ast)} = \frac1n\sum_{i=1}^n \log\frac{p_\theta(x_i)}{p_{\theta^\ast}(x_i)} \;\xrightarrow{\ \text{LLN}\ }\; \mathbb{E}_{\theta^\ast}\!\left[\log\frac{p_\theta}{p_{\theta^\ast}}\right] = -D_{\mathrm{KL}}(\theta^\ast\,\|\,\theta).

  • The right-hand side is <0 for \theta\ne\theta^\ast (Gibbs), so L(\theta)/L(\theta^\ast)\approx e^{-nD_{\mathrm{KL}}(\theta^\ast\,\|\,\theta)}\to 0.
  • So the likelihood (and therefore the posterior) piles up at \theta^\ast. This answers the question from the Bayes animation.

KL and entropy

Let u be uniform on m outcomes. Then D_{\mathrm{KL}}(p\,\|\,u) = \sum_x p(x)\log\big(m\,p(x)\big) = \log m - H(p),\qquad H(p) = -\sum_x p(x)\log p(x).

  • Maximising entropy is the same as minimising the KL divergence from uniform: choose the distribution that is hardest to tell apart from “know nothing”.
  • Ch 11 does this with constraints (MaxEnt), and Jaynes’ general version replaces u by a measure m(x), giving -D_{\mathrm{KL}}(p\,\|\,m).

A2: Fisher information from a Taylor expansion

Bernoulli: D_{\mathrm{KL}}(\theta\,\|\,\theta+\delta) = \theta\log\frac{\theta}{\theta+\delta} + (1-\theta)\log\frac{1-\theta}{1-\theta-\delta}.

Expand \log(1+u) = u - \tfrac{u^2}{2} + O(u^3): D_{\mathrm{KL}}(\theta\,\|\,\theta+\delta) = \frac{\delta^2}{2\,\theta(1-\theta)} + O(\delta^3) = \tfrac12 I(\theta)\,\delta^2 + O(\delta^3), \qquad I(\theta) = \mathbb{E}\!\left[\left(\partial_\theta\log p_\theta\right)^2\right] = \frac{1}{\theta(1-\theta)}. (Checked in Wolfram Language.)

  • Bernstein–von Mises. Posterior \approx \mathcal N\!\left(\hat\theta,\ \frac{1}{n\,I(\theta^\ast)}\right) for large n.
  • Geometry. ds^2 = I(\theta)\,d\theta^2. With \theta = \sin^2\phi we get ds = 2\,d\phi, so [0,1] has length \int_0^1\frac{d\theta}{\sqrt{\theta(1-\theta)}} = \pi. The Jeffreys prior \propto\sqrt{I(\theta)} is Beta(\tfrac12,\tfrac12).
  • Three outcomes: p\mapsto 2\sqrt{p} sends the simplex to an octant of a sphere of radius 2. Gaussian (\mu,\sigma): the Poincaré half-plane.

A3: Neyman–Pearson in one line

Let \phi^\ast be the likelihood-ratio test (\phi^\ast = 1 when p_1 > k p_0), and let \phi be any other test with \mathbb{E}_0\phi\le\mathbb{E}_0\phi^\ast=\alpha. Then \sum_D (\phi^\ast - \phi)(p_1 - k\,p_0) \;\ge\; 0 because the two factors always have the same sign. Rearranging gives \mathbb{E}_1\phi^\ast - \mathbb{E}_1\phi \ge k(\mathbb{E}_0\phi^\ast - \mathbb{E}_0\phi) \ge 0, so \phi^\ast has at least as much power.
